EVENTHOUSE MARQUEE WEBSITE

Static multi-page website built with plain HTML, CSS and JavaScript.

Pages:
- index.html
- services.html
- gallery.html
- contact.html

Folders:
- css/styles.css
- js/site.js
- assets/logo.jpg
- assets/images/*

No React, Python or build step is required. Upload the complete folder to any static host.

The enquiry form prepares the visitor's message, copies it to the clipboard when permitted, and opens the business Instagram page because no public email or WhatsApp number was supplied in the source information.
