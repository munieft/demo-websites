Chun Fun How (London Victoria) website
======================================
Plain HTML, CSS and JavaScript. No framework, no build step, no server code.

Pages:  index.html  menu.html  story.html  cups.html  events.html  visit.html
Open index.html in a browser to preview, or upload the whole folder to any web host.

Where to change things
- Menu items and prices, opening hours, WhatsApp number, ordering link: assets/js/menu-data.js
- Food, coffee and seasonal lists: menu.html
- Colours and type: the :root block at the top of assets/css/style.css
- Photos and videos: assets/img and assets/video

Fonts (Fraunces, Jost, Noto Serif TC) load from Google Fonts. The map is a Google Maps embed.
Enquiry forms and the drink builder open WhatsApp with the message written out; nothing is stored.
