Tim's Cafe website
==================
Plain HTML, CSS and JavaScript. No build step, no frameworks.

  index.html        the page
  css/style.css     all styling and animation
  js/main.js        open/closed status, menu search, plate builder, photo viewer
  images/           photos (full size and 800px versions)

To publish: upload the whole folder to any web host. Open index.html to preview locally.

To change prices or dishes: edit the menu section in index.html. The "Build a plate"
extras are the JSON list near the bottom of index.html (id="extras-data"; prices in pence).
Opening hours: the table in index.html and the HOURS list at the top of js/main.js.
