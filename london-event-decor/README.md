# London Event Decor — Website

Premium static website for London Event Decor, Barnet.

## Files
- `index.html` — page markup
- `styles.css` — all styling
- `app.js` — navigation interaction
- `assets/` — logo and favicon

## Hosting
This is a plain static website. Upload the **contents of this folder** to any static hosting service and set the publish/root directory to this folder.

No build step, npm, Node, React, or Vite is required.

## Local preview
Open `index.html` directly in a browser, or serve this folder with any static HTTP server.

All local CSS, JS and asset paths are relative so the site also works when hosted under a subdirectory.
