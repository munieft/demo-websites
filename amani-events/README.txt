2. HOW TO PUT IT ONLINE
------------------------------------------------------------------------
Option A — drag & drop hosts (easiest):
  Netlify Drop (app.netlify.com/drop), Cloudflare Pages, or GitHub Pages.
  Just drop the whole "amani-events" folder in. Done.

Option B — traditional web hosting (cPanel / FTP):
  Upload the CONTENTS of the "amani-events" folder into your web root
  (usually public_html/). "index.html" must sit at the top level so it
  loads as the front page.

The site is fully relative-linked, so it works from any folder or domain
with no changes.

5. ABOUT "PROTECTING" THE SITE
------------------------------------------------------------------------
As requested, the site is built to make casual copying harder:
  • HTML, CSS and JavaScript are minified (compressed and hard to read).
  • Right-click "Save image" and image-dragging are disabled.
  • Everything is split across separate files rather than one page.

Please understand this is a DETERRENT, not true security. Anyone
technical can still reach the files, because a browser must download them
to display them — this is true of every website. For a public "sample",
the strongest protection is to upload lower-resolution or lightly
watermarked photos. We're happy to prepare a watermarked image set.
