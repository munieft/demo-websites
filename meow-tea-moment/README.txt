Meow Tea Moment Greenwich — website
===================================
Plain HTML, CSS and JavaScript. No build step, no frameworks.

Open index.html in a browser, or upload the whole folder to any web host.

  index.html          the page
  css/style.css       all styling and animation
  js/menu-data.js     menu, prices, add-ons, opening hours, closure notices (edit this to update the site)
  js/main.js          behaviour: menu filter/search, drink builder, live open/closed status, gallery
  assets/img, video   the shop's own photos and clips
